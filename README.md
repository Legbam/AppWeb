# 🖥️ AppWeb — Portfolio de projets web

Ce dépôt regroupe mes projets web front-end et full-stack, réalisés dans une démarche d'apprentissage pratique et de mise en application de compétences concrètes (API, JavaScript asynchrone, résolution de problèmes techniques réels).

## 📂 Projets

### 🌍 [UPOrbit](./uporbit)
Application météo interactive affichant les prévisions sur 7 jours pour certaines villes européennes, via l'API 7Timer.

**Points forts techniques :** intégration d'une API externe, JavaScript asynchrone (`async`/`await`), traitement de données JSON, résolution d'un problème CORS via un proxy PHP maison, bascule Celsius/Fahrenheit en temps réel, interface personnalisée.

`HTML` `CSS` `JavaScript` `PHP` `API REST`

➡️ [Voir le projet](./uporbit) · [README détaillé](./uporbit/README.md)

### ✅ [ToDo App](./todo-app)
Application de gestion de tâches permettant d'ajouter, cocher et supprimer des tâches simplement.

**Points forts techniques :** manipulation du DOM, gestion d'événements, logique JavaScript pure sans dépendance externe.

`HTML` `CSS` `JavaScript`
